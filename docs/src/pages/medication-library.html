Medication Library

A reference list of common medications used in clinic practice. Use this library when recording prescriptions during a visit.

Demo note: In production, this list would be loaded from a medications database table with search and filter capabilities.

Amoxicillin

Class: Antibiotic (Penicillin)

Common Dosage: 250–500 mg every 8 hours

Common Duration: 5–10 days

Caution: Allergy cross-reaction with Penicillin.

Paracetamol (Acetaminophen)

Class: Analgesic / Antipyretic

Common Dosage: 500–1000 mg every 4–6 hours

Common Duration: As needed, max 4 g/day

Caution: Risk of liver toxicity in high doses.

Ibuprofen

Class: NSAID (Anti-inflammatory)

Common Dosage: 200–400 mg every 6–8 hours

Common Duration: As needed

Caution: Avoid on empty stomach. Not for renal impairment.

Metformin

Class: Antidiabetic (Biguanide)

Common Dosage: 500–850 mg with meals

Common Duration: Long-term

Caution: Monitor renal function. Withhold before contrast procedures.

Atenolol

Class: Beta-blocker (Antihypertensive)

Common Dosage: 25–100 mg once daily

Common Duration: Long-term

Caution: Do not stop abruptly. Monitor heart rate and BP.

Salbutamol (Albuterol)

Class: Bronchodilator (Short-acting beta-2 agonist)

Common Dosage: 100–200 mcg inhaled as needed

Common Duration: As needed (rescue inhaler)

Caution: Overuse may indicate poor asthma control.
